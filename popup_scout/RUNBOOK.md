## 1. 기준일과 중복 목록

1. `TZ=Asia/Seoul date +%F` 결과를 기준일로 쓴다.
2. 상위 페이지를 열어 본문 전체를 `history.md`로 저장한다. 본문의 '누적 목록' 표가 중복 판정에 쓰인다.
3. 같은 날짜 하위 페이지가 이미 있으면 새로 만들지 않고 멈춘다.

## 2. 후보 15~20개 수집

웹 검색으로 찾는다. 같은 검색어만 반복하지 말고 세부 분류·채널·시기를 섞는다.

**세부 분류** (코드의 `SUBCATEGORIES`와 같은 이름을 쓴다)

- 리빙: 가구·인테리어 / 홈데코·조명 / 주방·테이블웨어 / 침구·패브릭 / 홈프래그런스 / 생활가전 / 식물·가드닝 / 문구·디자인 소품 / 라이프스타일 편집샵 / 반려동물 리빙 / 리빙 기타
- 유아동: 키즈 패션 / 완구·놀이 / 캐릭터 / 그림책·교구 / 육아용품 / 유아식·키즈 푸드 / 가족 체험형 / 유아동 기타

**채널**: 백화점(현대·신세계·롯데·갤러리아·AK), 복합몰(더현대·스타필드·롯데월드몰·IFC 등), 성수·한남·연남·북촌 등 스트리트 단독 팝업, 지방 거점(부산·대구·대전·광주·제주 등), 해외 브랜드 국내 첫 팝업, 리빙·베이비 페어 안의 팝업형 부스

**검색어 예**: `{세부 분류} 팝업스토어 {연도}년 {월}월`, `리빙 브랜드 첫 팝업`, `키즈 팝업 오픈`, `성수 팝업 {세부 분류}`, `백화점 유아동 팝업`, `{백화점명} 리빙 팝업`. 최근 6개월 각 달을 고루 검색한다.

**확인**: 후보마다 출처 페이지를 직접 열어 브랜드·장소·기간을 확인한다.

- 확인되지 않은 칸은 지어내지 말고 `"미확인"`으로 적는다 (종료일은 `null`).
- 오픈일을 확인하지 못하면 후보에 넣지 않는다. 기사에 연도가 없으면 기사 발행일로 연도를 정한다.
- `source_type`은 실제로 확인한 페이지 기준으로 고른다. 기사가 브랜드·유통사 발표를 인용하면 `"보도 기반 기사"`, 팝업 정보 사이트면 `"정보 사이트"`, 블로그·인스타 후기면 `"블로그·SNS"` (뒤의 둘은 코드가 제외한다).

후보를 `popup_scout.py` 맨 위 설명의 JSON 형식으로 `candidates.json`에 저장한다. `highlights`에는 공간 연출·체험 프로그램·한정 굿즈처럼 기획에 참고할 구체 요소를, `reference`에는 참고할 점을 1문장으로 적는다. 사규 §2 금칙어를 쓰지 않는다.

## 3. 검증

```
python3 popup_scout/popup_scout.py check --candidates candidates.json --today 기준일 --history history.md
```

선정이 10개 미만이면 2단계로 돌아가 후보를 더 찾는다. 두 번 보충해도 모자라면 모자란 채로 진행한다. 기준 미달 건으로 채우지 않는다.

## 4. 노션 반영

```
python3 popup_scout/popup_scout.py render     --candidates candidates.json --today 기준일 --history history.md > page.md
python3 popup_scout/popup_scout.py index-rows --candidates candidates.json --today 기준일 --history history.md > rows.md
```

1. 상위 페이지 아래에 하위 페이지를 만든다. 본문은 `page.md` 그대로, 아이콘은 🛋️.
2. 상위 페이지 '누적 목록' 표 맨 아래에 `rows.md`의 행을 덧붙인다. 표의 다른 행, 하위 페이지, 다른 내용은 건드리지 않는다.
